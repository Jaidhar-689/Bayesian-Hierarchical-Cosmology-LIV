# Bayesian Hierarchical Cosmology & LIV Analysis

## Overview
This project reproduces results from recent research in:
- Cosmological parameter estimation using H(z) data  
- Lorentz Invariance Violation (LIV) using GRB spectral lags  

It implements Bayesian inference techniques including MCMC, nested sampling, and hierarchical modeling.

---

## Features
- ΛCDM and OΛCDM cosmological models  
- Bayesian error correction for H(z) data  
- GRB spectral lag analysis (Cubic Spline & SBPL models)  
- Hierarchical Bayesian constraints on LIV energy scale  

---

## Tech Stack
- Python  
- NumPy, SciPy, Matplotlib  
- emcee, dynesty, bilby
